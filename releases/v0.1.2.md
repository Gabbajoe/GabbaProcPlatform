# GabbaProc Companion v0.1.2

A clearer companion interface with durable archive uploads and separate upload
and processing feedback. The production upload queue and worker are now live.

- Characters, Sync, Account and Settings tabs replace the long scrolling view.
- Separate animated bars show packets received and processed by the server.
- Local character names and realms identify uploads, with an explicit anonymous
  or named-upload badge. Local display names do not change upload privacy.
- Faster startup: credentials and character discovery load in the background.
- Durable local archive queues, retry handling and server confirmations.
- Configurable automatic upload interval and optional bandwidth limits.
- System-language detection (German or English fallback), with saved override.
- Linux desktop launcher uses a themed application icon.

Downloads: Windows x64 (`x64-setup.exe`), macOS Apple Silicon (`aarch64.dmg`),
macOS Intel (`x64.dmg`), Fedora x64 (`x86_64.rpm`), Debian/Ubuntu x64 (`amd64.deb`),
and portable Linux x64 (`amd64.AppImage`).

The addon collects data in WoW; the companion uploads exported snapshots.
Install the addon from https://www.curseforge.com/wow/addons/gabbaproctracker .
Account login is not available yet; operator invites create upload tokens.
Windows/macOS publisher signing and Apple notarization remain unavailable;
updater signatures are separate. Native macOS/Windows gameplay validation is pending.
