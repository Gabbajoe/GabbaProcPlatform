OPEN SOURCE. EXPLICIT CHOICES.

Know exactly what leaves your computer.

What is sent

Effect IDs, area groups, counters, combat exposure, retained segment data, export time and persistent collection/character identifiers. Name and realm only in named mode. No account folder names, local paths, chat, inventory or entire SavedVariables file.

Without names ≠ untraceable

Persistent identifiers make these data pseudonymous. IP addresses are processed for network delivery and abuse limits. Named contributions can reveal a character's identity. Removing a name cannot erase copies someone already downloaded.

How data are checked

Lua is parsed as data, never executed. The server checks sizes, known effects, counters, ownership and duplicate snapshots. Public statistics include accepted community submissions, not independently verified gameplay. Suspicious data are withheld.

Storage, deletion and limitations

We retain the latest cumulative totals and up to 301 supplied history segments per collection. The public API does not expose character UUIDs, device tokens or detailed timestamps. A valid device token can hide stored names or delete its contributions and revoke itself. Contact the operator for device transfer. History gaps remain possible. Authentication tokens are stored hashed on the server. The app prefers the system keychain and does not silently fall back to a plaintext token file.
