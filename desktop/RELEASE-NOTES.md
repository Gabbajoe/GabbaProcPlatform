## What's new

- Settings now has App preferences, Version and updates, and About tabs.
- The update page shows your installed version, available version and release notes. Manual checks do not start installation: read the changes, then choose Install update and restart.
- All headings use GabbaProc blue. Website and companion share the white/blue wordmark and “Count the sparks!” slogan.
- About links to the community website and the public source/release repository.
- Existing account connections, character selections and upload settings are preserved.
