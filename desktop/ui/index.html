GabbaProc Companion

Small app. Shared discoveries.

1 · Connect

Get an upload token from gabbaproc.kellerkind.info using an operator invite. Paste it here. It is stored in your system keyring, or only for this session when unavailable.

2 · Choose characters

Export in the addon (/gpt export), then /reload or log out. Only selected characters are uploaded. Anonymous uploads use a persistent pseudonymous ID.

3 · Synchronize

Closing the window keeps the app running in the tray. Use the tray menu or Quit app to exit completely. Without an available tray, closing quits the app. Anonymity does not remove copies of previously public names.
